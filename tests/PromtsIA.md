# Prompts per crear i ampliar les proves

1. **Prompt:** «Generem una sèrie de programes per executar proves, per validar que funciona el codi del entorn del servidor i el del client.»  
   **Explicació:** crear proves executables per comprovar el funcionament del servidor i del client.

2. **Prompt:** «Vull que les proves siguin més precises, fes més llarg el document de test del servidor.»  
   **Explicació:** ampliar els casos del servidor per comprovar amb més detall les dades i les respostes de l'API.

3. **Prompt:** «Has de fer tests sobre el GET, POST, PUT i el DELETE del que els tinguin.»  
   **Explicació:** provar les operacions HTTP que tingui implementades cadascun dels recursos.

4. **Prompt:** «Inclou el test dintre del src que és la carpeta main i fes els testos.»  
   **Explicació:** posar i executar els tests del servidor dins de `src`.

5. **Prompt:** «Ara hem de fer la carpeta test dintre de client react src uns testos precisos sobre el funcionament del codi.»  
   **Explicació:** crear tests precisos del client React dins de `src/test`.

6. **Prompt:** «Hazme más pruebas para el de React necesito hacer más test.»  
   **Explicació:** augmentar els tests del client per cobrir més casos de renderitzat, dates i selecció de dades.
